T.J. Rodriguez - Local Favorites Tracker

A tracker built to keep track of your favorite places in your local area. This was built from scratch in HTML, JavaScript, and CSS for WRIT 40363.

This tracker is also a demonstration on how I am growing in my knowledge of JavaScript and how it affects user interaction with a site.

**Live site:** https://tjrod28.github.io/local-favorites-tracker/

## Built with

- Semantic HTML5
- CSS with design tokens, Flexbox, and Grid
- Git and GitHub Pages
- JavaScript
